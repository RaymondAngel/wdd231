FINAL PROJECT ORGANIZATION

Root HTML files: published pages and the original site plan.
styles/: shared website CSS and separate site-plan CSS.
  CSS order: foundation, skip link, header/navigation, main content, footer,
  then responsive overrides. Shared components are defined once and reused.
scripts/: runtime ES modules and existing project verification utilities.
data/: service catalog JSON.
images/: assets referenced by published pages (logo, process, and favicons).
notes/: planning, submission instructions, and original image prompts.
notes/source-assets/: original logo variants and full-size favicon artwork;
  these are retained as unique source files rather than served page assets.
reports/: existing validation evidence, browser screenshots, and audit reports.
